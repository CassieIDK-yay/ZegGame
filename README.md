# Maze Escape

Prosta gra typu Labirynt wykonana w HTML, CSS i JavaScript.

Gracz porusza się po mapie, zbiera klucze i unika przeciwników.

# Technologie

- JavaScript
- Canvas API

# Funkcje gry
- poruszanie WASD i strzałkami
- przeciwnicy
- system HP
- 3 poziomy
- klucze
- restart gry
- ekran startowy
- animacje postaci
